# She Can Foundation

A webpage I built as part of the frontend internship selection task for She Can Foundation — a youth-driven NGO working on education and digital initiatives across India.

The task was to create a simple single-page site. I kept it clean but added a few extra things like scroll animations, hover effects, and responsive layout.

## What's inside

- `index.html` — page structure
- `style.css` — all the styling
- `script.js` — scroll animations and small interactions

## Sections

Navbar → Hero → About → Internship Info → Footer
